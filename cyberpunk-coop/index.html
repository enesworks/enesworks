An EnesWorks open-source experiment

One campaign.
Two Vs.

A research-driven attempt to build a two-player, shared-story co-op mod for Cyberpunk 2077 and Phantom Liberty. Each player keeps a personal V while both players follow one agreed campaign state.

Development status: This project is not currently a playable multiplayer mod. Online login, Epic invitations, player replication, mission synchronization, and Vortex release are not implemented yet.
Unofficial fan-made project

One shared story

Story-changing choices must resolve to the same outcome for both players before common progress advances.

Two personal Vs

Builds, equipment, currency, and ordinary loot stay with each player's own character.

Native game behavior

The project is designed to preserve Cyberpunk's authored AI and mission behavior rather than replace them with arbitrary rules.

Where development stands

The repository contains early native-plugin, story-coordination, packet-validation, and EOS SDK loading components. They are not connected to a working in-game multiplayer session. No campaign mission is marked supported, and no public Vortex release is available.

Epic Account Services is being configured for development. The current application is an unreviewed draft; Epic accounts outside the developer organization cannot authenticate until the brand is reviewed. No claim of Epic approval or CD Projekt Red affiliation is made here.
