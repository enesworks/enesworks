Privacy & data handling

Last updated: 25 October 2026 · Project maintainer: EnesWorks

Pre-release notice: The current plugin does not provide online play, Epic sign-in, friend-list access, or multiplayer networking. The sections below distinguish the current build from planned behavior. This notice must be reviewed and updated against the shipped implementation before online features are enabled or a public brand-review request is submitted.

Who operates this project?

CyberpunkCoop is an unofficial, open-source fan project maintained by EnesWorks. It is not affiliated with or endorsed by CD PROJEKT RED or Epic Games. Privacy questions can be sent to enesyasatmaz5@gmail.com.

What the current build does

The current source is an early development scaffold. It does not authenticate Epic accounts, read a user's friends list or presence, create an online lobby, send gameplay data to another player, or operate a project-owned backend. The project website is a static site and does not include analytics, advertising, tracking pixels, or third-party scripts.

GitHub hosts this website and the source repository. GitHub may process ordinary web-request and security logs under its own privacy terms: GitHub Privacy Statement.

Planned account and multiplayer data

If Epic Online Services (EOS) account and invitation features are implemented, the client is expected to request these Epic permissions:

  • Basic Profile: Epic account identifier and display name, to identify the local player and show who is in the session.
  • Online Presence: presence needed to support Epic social invitations and lobby status.
  • Friends: friend-list access needed to present or select an Epic friend for an invitation.

During a future co-op session, the two participating game clients would exchange only the session and game-state information needed to play together, such as peer identity, position, actions, mission checkpoint, and shared story revision. The current design uses EOS services for account identity and peer-to-peer transport; no project-operated gameplay server or analytics service is planned.

Storage and retention

The current build does not store EOS account data because EOS login is not active. The planned session design keeps live peer and gameplay state in memory for the session. It is not designed to store Epic credentials, access tokens, or friends lists in a save file or on a project server. Any later diagnostic logging or local cache behavior will be documented before online release. Epic handles EOS account data according to Epic's own terms and privacy notices.

Choices and requests

Users can decline the Epic consent screen and choose not to use online features. For questions about data held by this project, contact the maintainer above. For Epic account data, use Epic's account privacy and data controls. This project cannot delete data held by Epic.

Changes

This notice describes the current pre-release source and the intended design, not a launched service. It will be revised if the implementation, permissions, storage, or sharing behavior changes. The release version of this notice must describe actual software behavior and will be published before public multiplayer access is requested.
